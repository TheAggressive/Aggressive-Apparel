# Copy review — November 20, 2026

Before-and-after record of the brand voice pass. The rules it applies, and
the ones it enforces in CI, are in [`brand-voice.md`](brand-voice.md).

**Inventory.** `languages/aggressive-apparel.pot` holds every theme-owned
string: 2,174 msgids, about 1,650 of them customer-facing (the rest are
admin and editor UI). Every customer-facing string was scanned for the voice
guide's retired phrases, unsupported claims, invented people and shouted
messages; matches were reviewed in context. WooCommerce's and plugins' own
strings were not overridden.

## Site content to review in WordPress (not changed)

Saved in the database, so a theme release doesn't change it:

1. **Free-shipping threshold conflict.** The footer says "FREE SHIPPING OVER
   $75"; the free-shipping message (driven by the shipping settings) shows
   "$105 away" on a $45 cart, i.e. a $150 threshold. One of them is wrong.
2. **Announcement bar:** "TRENDS DIE. ATTITUDE DOESN'T." is borrowed attitude;
   "LATEST DROP LIVE NOW" should name the drop or go.
3. **Footer:** "NEW RELEASES. RESTOCKS. EXCLUSIVES." promises restocks and
   exclusives; "Premium, confident, authentic" describes rather than shows.
4. **Navigation:** "MENS" / "WOMENS" need apostrophes (Men's / Women's).
